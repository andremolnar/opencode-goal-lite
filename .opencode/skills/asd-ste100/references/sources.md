# Sources and Adaptation Scope

## Primary standard

- ASD Simplified Technical English Maintenance Group. *ASD-STE100 Simplified
  Technical English*, Issue 9, 15 January 2025.
  https://www.asd-ste100.org/assets/files/ASD-STE100_ISSUE9.pdf

ASD-STE100 defines 53 writing rules and a controlled dictionary. The dictionary
is not reproduced in this skill. The official publication remains the source of
truth for formal compliance.

## Published skill used as the adaptation source

- danyuchn/asd-ste100-skill, MIT License.
  https://github.com/danyuchn/asd-ste100-skill

This Coach skill adapts the published skill's agent-facing scope and its
preservation-first rewrite principle. It adds explicit rules for lossless
summaries, subagent handoffs, source attribution, and separating facts from
assumptions and recommendations.

## Scope

This is an ASD-STE100-inspired controlled-English profile. It is not an
ASD-certified tool or a substitute for an official dictionary check.
