# Changelog Rules

Use the following format for the changelog. The changelog is located in `CHANGELOG.md`.

```markdown
## [x.x.x] - 20xx-xx-xx

### Added

### Changed

### Fixed

### Deprecated

### Breaking changes
```

# Changelog Standards

- The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
- and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html) (MAJOR.MINOR.PATCH)
- Document all changes in a `CHANGELOG.md` file.
- Include version number, date, and list of changes.
- Categorize changes as: Added, Changed, Deprecated, Removed, Fixed, Security.
- Link to relevant issues or pull requests when applicable.
